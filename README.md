# Task Calendar — Obsidian 任务日历插件

一款基于 **Obsidian Task 语法** 的任务日历插件，支持月视图和周视图，多日任务以连续长条展示，可拖拽调整日期范围。

---

## 快速开始

### 安装

1. 从 [Releases](https://github.com/BornfreeYan/obsidian-task-calendar/releases) 下载 `main.js`、`manifest.json`、`styles.css`
2. 放入 Obsidian vault 的 `.obsidian/plugins/obsidian-task-calendar/` 目录
3. 重启 Obsidian，在设置 → 社区插件中启用 **Task Calendar**

### 使用

- 点击左侧 Ribbon 日历图标，或执行命令面板中的 `Open Task Calendar`
- 插件自动扫描你指定的路径，识别所有符合 Task 语法的任务

---

## 支持的 Task 语法

```markdown
- [ ] 单日任务 🛫 2026-07-22
- [ ] 多日任务 🛫 2026-07-20 📅 2026-07-25 #工作
- [x] 已完成任务 🛫 2026-07-21 📅 2026-07-21 ✅ 2026-07-21
```

| Emoji | 含义 | 说明 |
|-------|------|------|
| `🛫` | 起始日期 | 任务开始日期（必须有） |
| `📅` | 终止日期 | 任务截止日期（可选，无则视为单日） |
| `#tag` | 标签 | 任意标签，用于筛选和配色 |
| `✅` | 完成日期 | 标记任务完成时间 |

**单日任务**：只写一个日期（`🛫` 或 `📅` 均可）
**多日任务**：同时写 `🛫` 和 `📅`，横跨期间在日历中显示为连续长条

## 功能概览

### 视图切换

Toolbar 左侧分段按钮切换：

| 视图 | 说明 | 导航 |
|------|------|------|
| **月** | 月历，多日任务显示为跨日长条 | ±1 月 |
| **周** | 周一~周日 七列任务列表 | ±7 天 |

### 多日任务长条（月视图）

- 横跨多天的任务以**连续长条**显示在日期行下方
- 长任务在上，短任务在下
- 跨周任务自动截断，下周继续显示
- 点击长条中间打开文件，拖拽左右边缘调整日期

### 拖拽调整日期

**月视图专属功能**：

| 操作 | 效果 |
|------|------|
| 拖拽长条左边缘 | 调整起始日期 `🛫` |
| 拖拽长条右边缘 | 调整终止日期 `📅` |
| 拖拽单日卡片边缘 | 展开/收缩为更多天数 |

拖拽时显示 tooltip 预览新日期，释放后自动写入原文件。

### 已完成任务

- 已完成任务显示为**灰显 + 删除线**
- 无论单日还是多日，已完成任务始终沉到**最底部**

### 右键新建任务

任意日期格子右键 → 新建任务，自动在指定路径创建文件并写入 Task 语法。

### 筛选与配色

Toolbar **筛选**和**分类配色**按钮：

- **筛选**：按标签 / 描述关键词排除任务
- **配色**：按标签 / 描述关键词匹配颜色
  - **标签条**：任务左侧 3px 色条
  - **整块**：任务整体底色

## 扫描路径配置

Toolbar **扫描路径**按钮 → 选择要扫描的文件夹或文件。

- 默认扫描全部 Markdown 文件
- 支持多路径选择（适合 Daily Notes 文件夹 + 独立任务文件的场景）
- 修改后即时生效

## 技术架构

| 层 | 技术 |
|---|------|
| 运行时 | Obsidian Plugin API |
| 语言 | TypeScript 4.7 |
| 构建 | esbuild 0.17（打包为 `main.js`） |
| 样式 | 原生 CSS（CSS Grid + Flexbox） |

### 源码文件

```
taskParser.ts         — 任务解析引擎（核心基石）
calendar.ts           — 月/周视图渲染 + 工具栏 + 交互
view.ts               — TaskCalendarView 主视图 + 数据层
main.ts               — 插件入口 + 设置持久化
settings.ts           — 类型定义 + 预设色板
queryPathModal.ts     — 扫描路径配置弹窗
colorRulesModal.ts    — 分类配色规则管理弹窗
filterModal.ts        — 筛选规则管理弹窗
styles.css            — 全部样式
```

### 构建

```bash
npm install        # 安装依赖
npm run build      # 类型检查 + esbuild 生产构建
npm run dev        # 开发模式（文件变更自动构建）
```
